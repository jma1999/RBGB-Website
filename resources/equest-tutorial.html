Energy Modeling in eQUEST

A practical onboarding course for students, enthusiasts, and project teams learning how to set up, review, document, and interpret whole-building energy models using eQUEST.

Beginner Friendly 7 Modules Internal Training eQUEST Workflow

Course Overview

From drawings to decisions.

This course helps learners understand how energy models support design decisions, LEED documentation, code compliance, energy strategy, and performance optimization.

The focus is not just clicking through software. The goal is to understand what the model represents, how assumptions affect results, and how to communicate findings clearly to a project team.

What you will learn

Read project information

Understand how drawings, schedules, systems, envelope data, and owner goals become model inputs.

Build a clean baseline

Learn how to set up geometry, zoning, schedules, loads, HVAC systems, and utility assumptions.

Review outputs critically

Interpret end-use results, unmet hours, warnings, energy savings, and model reasonableness.

Starter Checklist

Before starting a model

  • Confirm project location and weather file.
  • Collect architectural drawings, floor plans, elevations and sections.
  • Identify building area, orientation, number of floors and major space types.
  • Review envelope assemblies, glazing type, roof, wall and window values.
  • Collect mechanical system information and basis of design.
  • Confirm lighting power density, plug loads and operating schedules.
  • Clarify whether the model is for LEED, code compliance, tax analysis or design strategy.
