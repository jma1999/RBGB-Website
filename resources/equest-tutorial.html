Energy Modeling in eQUEST

ASHRAE 90.1 Appendix G | Proposed + Baseline Models | Design Development Wizard

This course breaks down an eQUEST model step by step through the LEED energy modeling process. We will model a building using the Design Development Wizard, develop the proposed building, create the Appendix G baseline model, run simulations, review results, and prepare the reports needed for LEED submission.

The goal is not only to learn the software, but also to understand the relationship between the baseline and proposed models; we will also understand how energy models support code compliance, LEED documentation, design decisions, energy strategy and performance optimization.

Course Path

From design documents to LEED energy reports.

This tutorial starts with design documents and ends with the eQUEST reports and supporting documentation required for a LEED energy model review. The workflow follows the logic of ASHRAE 90.1 Appendix G: first build the proposed model, then create the baseline model by modifying the proposed model according to Appendix G rules.

Part I

Getting Started

Before opening eQUEST, understand what the model is being used for. For a LEED energy model, the purpose is not only to predict energy use, but to compare the proposed building against an ASHRAE 90.1 Appendix G baseline building.

Five things to know before modeling

  • The model needs both a proposed building and a baseline building.
  • The proposed model should follow the design documents.
  • The baseline model is not a real building; it is an Appendix G comparison building.
  • The proposed and baseline models should use the same simulation program, weather data, and energy rates.
  • The final LEED submission needs clear documentation, assumptions, outputs, and explanation of errors or warnings.

Part II

Starting the Proposed Building in eQUEST

The proposed building model represents the actual design. In this course, do not start with the Schematic Wizard. Start directly with the Design Development Wizard so the model can be developed with more detailed project inputs.

Important workflow decision

Start with the Design Development Wizard, not the Schematic Wizard. This gives better control over building shells, zones, HVAC systems, schedules, envelope values, lighting power density and project-specific inputs.

Step 01

Start a New File in eQUEST

Create a new eQUEST project file and save it in a clean project folder. Keep the file name clear and version-controlled so future proposed and baseline versions can be tracked.

  • Create a new eQUEST project.
  • Save the file using a clear name, such as ProjectName_Proposed_v01.
  • Create folders for drawings, assumptions, screenshots, outputs and LEED reports.
  • Keep a separate assumptions log from the beginning.

Step 02

Set Project Location, Weather and Utility Rates

Select the project location and weather file carefully. The weather file affects heating, cooling, ventilation and energy results. For Appendix G modeling, proposed and baseline models should use the same weather data and the same energy rates.

  • Select the closest representative weather location.
  • Confirm climate zone for later baseline system decisions.
  • Enter utility rates or use an agreed project energy cost method.
  • Document the weather file and utility-rate source in the assumptions log.

Step 03

Create Building Shells and Draw the Building

Use the Design Development Wizard to create the building shell. This is where the basic geometry, floor areas, number of floors, floor heights and orientation are established.

  • Confirm gross square footage from drawings.
  • Confirm number of floors and floor-to-floor height.
  • Draw the building footprint carefully.
  • Check orientation against the site plan or north arrow.
  • Create the second floor or additional floors as needed.
  • Review the Project Navigator and building shell tree.

Step 04

Create Custom Zones and Thermal Blocks

Zoning is one of the most important modeling decisions. For LEED modeling, zones should be simple enough to manage but accurate enough to represent major space types, schedules, exposure and HVAC service areas.

  • Use custom zones where the default zones do not match the design.
  • Group similar spaces when they have similar schedules, loads and HVAC service.
  • Separate spaces with very different loads or schedules.
  • Rename spaces clearly so LEED reviewers can understand the model.
  • Create a thermal-block diagram for documentation.

LEED documentation habit

Keep zone names readable. Avoid generic names like “Zone 1” or “Space 2.” Use names such as “Level 1 Office North,” “Conference Zone,” or “Corridor Core.”

Step 05

Use System Setup Wizards and Assign Zones

Set up the proposed HVAC system based on the design documents. The proposed model should reflect the actual system type, zoning, capacities, efficiencies, ventilation assumptions and controls where available.

  • Use the system setup wizard to create the proposed HVAC system.
  • Assign zones to the correct systems.
  • Set plant equipment where applicable.
  • Set domestic hot water system assumptions.
  • Check airside systems, waterside HVAC, pumps and fans.
  • Document any assumptions that are not available in the drawings.

Step 06

Move into Detailed Mode

After the main wizard inputs are complete, move into Detailed Mode to review and refine the model. Detailed Mode is where you clean up names, check schedules, adjust parameters and prepare the model for LEED-level review.

  • Review building shells, floors and spaces.
  • Rename spaces and zones clearly.
  • Check schedules for occupancy, lighting, plug loads and HVAC operation.
  • Review HVAC system assignments.
  • Confirm plant and domestic hot water inputs.

Step 07

Lighting, Plug Loads, People and Ventilation

Internal loads can strongly affect model results. For LEED, these inputs should be traceable to drawings, schedules, owner information, design assumptions or ASHRAE defaults where appropriate.

  • Set lighting power density using the correct method.
  • Use global parameter LPD where appropriate.
  • Set plug loads and equipment loads.
  • Set people density and occupancy schedules.
  • Set ventilation assumptions and outdoor air rates.
  • Check whether the space-by-space or whole-building method is being used.

Review-comment risk

Lighting, plug loads, schedules and ventilation are common sources of LEED review comments. Always document the source of each input.

Step 08

Window Setup, Materials and U-Values

The proposed envelope should match the design documents. This includes walls, roofs, floors, glazing, window-to-wall ratio, U-values, SHGC, reflectivity and other envelope assumptions.

  • Review window areas and window-to-wall ratio.
  • Enter glazing U-value and SHGC.
  • Enter wall, roof and floor constructions.
  • Check material layers and assembly U-values.
  • Document any assumptions where the design documents are incomplete.

Step 09

Detailed System Setup

Refine the proposed HVAC model. Review system type, air handling units, fans, coils, boilers, domestic hot water, controls, efficiencies and system-specific parameters.

  • Check air handling unit setup.
  • Confirm fan power and fan curves.
  • Set cooling and heating coils.
  • Set boiler and domestic hot water inputs.
  • Review efficiency and performance curves.
  • Check exhaust fans and room exhaust.
  • Review system specifics before simulation.

Step 10

Simulate the Proposed Building

Run the proposed model and review errors, warnings, unmet hours and end-use results. Do not move to the baseline model until the proposed model is stable and explainable.

  • Run the proposed simulation.
  • Review eQUEST error messages.
  • Check unmet heating and cooling hours.
  • Review energy use by end-use category.
  • Check whether results are reasonable for the building type.
  • Save this as the clean proposed model before creating the baseline.

Part III

Creating the Baseline Building

The baseline model is created by modifying the proposed model according to ASHRAE 90.1 Appendix G. Do not create a completely unrelated model. The baseline should keep items that Appendix G requires to remain the same and modify only the prescribed baseline elements.

Recommended file workflow

  • Save a clean copy of the proposed model.
  • Duplicate it and rename the duplicate as the baseline model.
  • Modify the duplicate according to Appendix G baseline requirements.
  • Keep a clear list of every change made from proposed to baseline.

Step 11

Baseline Envelope and Glass

Update the baseline envelope according to Appendix G rules. This may include changing glazing type, window-to-wall ratio, roof reflectivity, wall assemblies, roof assemblies and other envelope properties.

  • Determine the applicable baseline envelope requirements.
  • Update glass type and glazing values.
  • Check percent glass and window-to-wall ratio.
  • Update walls, roof and floor constructions.
  • Update roof reflectivity and U-values where required.
  • Document every baseline envelope change.

Step 12

Baseline Lighting, Loads and Schedules

Review which inputs remain identical to proposed and which must be changed for baseline. Lighting power density is often modified according to ASHRAE 90.1 requirements, while many schedules and process loads may remain consistent unless Appendix G requires otherwise.

  • Update baseline LPD according to the selected method.
  • Review schedule consistency between proposed and baseline.
  • Keep process loads consistent unless a documented exception applies.
  • Check exterior lighting and parking lot lighting where applicable.
  • Document all baseline assumptions clearly.

Step 13

Baseline HVAC Systems

Determine the baseline HVAC system type using Appendix G rules. Baseline system selection depends on factors such as building type, number of floors, conditioned floor area, residential or nonresidential use and climate zone.

  • Determine the correct baseline system type.
  • Create air handling units for required floors or zones.
  • Set airside parameters.
  • Set heating and cooling systems.
  • Set fan power, MERV filters and system efficiencies.
  • Set waterside HVAC, pumps, boilers and domestic hot water.
  • Check thermal block simplification and PTAC/PTHP assumptions where applicable.

Baseline system warning

Do not simply copy the proposed HVAC system and call it baseline. Appendix G often requires a specific baseline system type even when the actual proposed design uses a different system.

Step 14

Simulate the Baseline Building

Run the baseline model and review it with the same discipline as the proposed model. Check errors, warnings, unmet hours, end-use results and major differences between proposed and baseline.

  • Run the baseline simulation.
  • Review errors and warnings.
  • Check unmet hours.
  • Compare end-use results against the proposed model.
  • Check whether savings make sense.
  • Revise assumptions if errors or unreasonable results appear.

Part IV

Energy Modeling for LEED

The final phase is about review, documentation and submission quality. A technically correct model can still receive review comments if the assumptions, reports and explanations are not clear.

LEED reviewer mindset

Make the model easy to review. Explain what changed between proposed and baseline, where inputs came from, how systems were selected, and why the results are reasonable.

Step 15

Prepare LEED Documentation

ASHRAE 90.1 Appendix G documentation typically includes a project summary, model software and version, energy analysis results, project overview, energy-related features, compliance list, floor plans, elevations, thermal block diagrams, assumptions, input/output reports, unmet hours and error explanations.

  • Prepare project description and building-use summary.
  • Document software name and version.
  • Include proposed and baseline performance results.
  • Prepare end-use breakdowns.
  • Include floor plans and elevations.
  • Include thermal block diagrams.
  • Explain major assumptions.
  • Include input and output reports.
  • Explain errors, warnings or unmet-hour issues.

Step 16

Reduce LEED Review Comments

Many review comments come from unclear assumptions, missing reports, inconsistent schedules, unexplained unmet hours, mismatched proposed/baseline inputs or baseline systems that do not follow Appendix G.

  • Check that proposed and baseline use the same weather file and rates.
  • Confirm proposed model matches design documents.
  • Confirm baseline model follows Appendix G rules.
  • Check that schedules are consistent where required.
  • Check LPD, plug loads, ventilation and process loads carefully.
  • Explain unmet hours and any unusual energy-use patterns.
  • Keep screenshots of key eQUEST windows for documentation.
