Energy Modeling in eQUEST

Beginner Course | eQUEST Workflow | New Hire Resource

This course introduces new hires to the role of energy modeling in high-performance building projects, with a practical focus on eQUEST workflows, project setup, assumptions, simulation outputs and quality review.

The goal is not only to learn the software, but to understand how an energy model supports code compliance, LEED documentation, design decisions, energy strategy and performance optimization.

Course Path

From project information to model results.

Use this page as a working tutorial. Each section can later be updated with screenshots from eQUEST, short walkthrough videos, downloadable files, and project-specific notes.

01

Introduction to Energy Modeling

Energy modeling is the process of simulating a building’s energy use based on geometry, envelope, schedules, internal loads, HVAC systems, controls and weather data.

In project work, an energy model can support LEED documentation, code compliance, tax analysis, design comparison, energy conservation measures and whole-building performance strategy.

02

Opening eQUEST and Starting a Project

Start by opening eQUEST and creating a new project file. The wizard workflow is useful for setting up the main project assumptions before moving into detailed edit mode.

  • Create a new project.
  • Confirm the project name and file location.
  • Select the correct weather location.
  • Choose the appropriate building type and initial setup options.

03

Project Location, Weather File and Building Type

The project location and weather file are important because weather conditions drive heating, cooling, ventilation and load calculations.

Confirm the location carefully before continuing. If the weather file is wrong, the results can be misleading even if the rest of the model is built correctly.

04

Building Geometry and Zoning

Geometry defines the shape, size and orientation of the building. Zoning determines how spaces are grouped thermally.

  • Confirm total floor area.
  • Check number of floors and floor-to-floor height.
  • Review orientation and building form.
  • Group similar spaces into reasonable thermal zones.

05

Envelope, Lighting, Loads and Schedules

The envelope and internal load assumptions strongly affect energy use. These inputs should be based on drawings, specifications, schedules, owner requirements or clearly documented assumptions.

  • Walls, roofs, windows and insulation values.
  • Glazing type, window-to-wall ratio and shading.
  • Lighting power density.
  • Plug loads and equipment loads.
  • Occupancy and operating schedules.

06

HVAC Systems and Controls

HVAC system inputs should reflect the design documents or agreed modeling assumptions. The system type, efficiency, fan power, ventilation and control strategy can significantly affect model results.

  • Select the appropriate HVAC system type.
  • Input heating and cooling efficiencies.
  • Review ventilation assumptions.
  • Check fan power and control settings.
  • Confirm economizer and setback assumptions where applicable.

07

Running the Simulation and Reading Outputs

After the model is built, run the simulation and review the output reports. Do not only look at the final energy number. Check errors, warnings, unmet load hours and end-use breakdowns.

  • Run the simulation.
  • Review error and warning messages.
  • Check unmet heating and cooling hours.
  • Review annual energy use by end-use category.
  • Compare results against expectations or benchmark data.

08

QA/QC and Documentation

A model is only useful if the assumptions are clear and the results are reasonable. Before sharing outputs, review the model carefully and document where the inputs came from.

  • Check model inputs against drawings and specifications.
  • Confirm assumptions that were not available in documents.
  • Review reasonableness of results.
  • Document key inputs, sources and notes.
  • Prepare a summary for internal or client review.
